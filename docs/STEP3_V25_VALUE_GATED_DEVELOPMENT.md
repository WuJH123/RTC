# Project7 Step3 V25 value-gated Development lane

V25 is a Development-only repair for the V24 high-stress escape defect. It does not modify the
historical V23 or V24 runtimes or their evidence.

## Frozen policy contract

The existing V23 candidate portfolio is built once per decision and ranked by the frozen V15 rank
branch. The selected candidate is passed through a matched H120 value calibrator trained only on
the current-V23 selected-candidate Development/Train truth bank. The runtime executes only when

```text
TFV_UCB = predicted_delta_TFV_H120 + calibrated_one_sided_error_margin < 0
```

The value estimand is

```text
TFV_H120(candidate H10 + frozen causal continuation)
- TFV_H120(HOLD H10 + identical frozen causal continuation)
```

Unknown value, invalid lineage, passive-channel changes, engineering infeasibility, or sequence
support violations fail closed to HOLD. Hydraulic stress and strong-storm blend are telemetry and
features only; they cannot authorize an action. `TYPE_AWARE_HYDRAULIC_PRESSURE` is not an escape
path and is evaluated by the same ranking and value gate as every other portfolio candidate.

## Data and firewall

The matched bank contains 48 unique rainfall groups. One current-V23 hydraulic action hash was
reused from existing exact truth and 47 missing current-policy action hashes were generated by the
minimal Development-only counterfactual job. Existing shared HOLD branches were reused. No
Validation, Calibration, Locked, Final, or Formal labels are used by the calibrator.

The V25 lane remains `development_only=true`, `formal_evidence=false`, and
`ready_for_policy_lock=false`.
